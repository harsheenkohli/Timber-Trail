# Timber Trail

Timber Trail is a fun and interactive browser-based game where players stretch sticks to help the hero cross platforms. The game challenges players to aim for perfect hits to score double points while avoiding falling off the platforms.

## Features
- **Dynamic Gameplay**: Stretch sticks to cross platforms and score points.
- **Perfect Hit Bonus**: Earn double points for hitting the perfect area.
- **High Score Tracking**: Your highest score is saved locally.
- **Responsive Design**: The game adjusts to different screen sizes.
- **Interactive Sounds**: Enjoy sound effects for actions like scoring and falling.

## How to Play
1. **Start the Game**: Click anywhere on the screen or press the spacebar to restart.
2. **Stretch the Stick**: Hold down the mouse or touch the screen to stretch the stick.
3. **Release**: Let go to drop the stick and help the hero cross to the next platform.
4. **Score Points**: Aim for the perfect area to earn double points.
5. **Avoid Falling**: If the stick is too short or too long, the hero will fall.

## Controls
- **Mouse/Touch**: Hold to stretch the stick, release to drop it.
- **Keyboard**: Press the spacebar to restart the game.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/harsheenkohli/Timber-Trail.git
   ```
2. Open the `index.html` file in your browser to start playing.
